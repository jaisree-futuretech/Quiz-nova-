# QuizNova

**Live Demo:** https://jaisree-futuretech.github.io/Quiz-nova-/

A quiz application designed for students to test their knowledge through timed quizzes and receive instant results based on their performance.

## Features

- User-friendly quiz interface
- Multiple-choice questions
- Timed quizzes
- Score calculation
- Instant results
- Question navigation
- Performance tracking
- Responsive interface

## Tech Stack

- Java
- HTML
- CSS
- JavaScript

## How It Works

1. Start a quiz.
2. Answer the questions within the given time.
3. Navigate through the available questions.
4. Submit the quiz.
5. View the final score and performance.

## Project Focus

This project demonstrates:

- Core programming logic
- Quiz and scoring logic
- Timer implementation
- User interaction
- Conditional logic and data handling
- Frontend development

## Run Locally

1. Clone the repository.
2. Open the project files.
3. Run the application according to the project setup.
